# Legion del mal

> _"El mundo no se conquista con fuerza bruta, se conquista con un buen plan y control de versiones."_
> -Lex Luthor, fundador

## ¿Quienes somos?

Somos la alianza definitiva de supervillanos. Mientras los héroes se dividen entre Metróplis, Gotham y New Yoork, nosotros hemos hecho lo que ellos jamás lograron: unirnos. Nuestra misión es simple: dominar el mundo y demostrar que la maldad organizada es más efectiva que la justicia desorganizada. DC, Marvel, no importa el universo - aquí solo importa el objetivo.
